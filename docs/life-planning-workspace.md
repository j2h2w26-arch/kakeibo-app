# 人生設計ワークスペース

更新: 2026-09-20

設計チャットの読み取れた追補と利用者の実装依頼を、この実装の仕様として整理したもの。添付された設計書本体は未取得。

- 保存は一覧に残す。達成済み、アーカイブを個別に閲覧でき、アーカイブは取り消し・復元できる。
- 年月指定、未定、3/6か月、1/2/3/5/10/20年のクイック指定。既存の日付は年月を変更するまで保持する。
- 目標同士を「支える／前提／関連」で結ぶ。共通ToDoは1ノード。自動整列、拡縮、スクロール移動、フォーカス絞り込み、選択で詳細表示。
- フェーズを順序付きで追加・編集。目標ごとのロードマップに節目とToDoを紐付ける。日付と状態を編集できる。
- 横断タイムラインは1/3/5/10/20年・全期間。目標・フェーズ・節目の年月を移動でき、キーボード・タッチ向け年月入力も併設。
- スマホは表示／詳細の切替、iPad横は一覧と作業面、PCは左ナビ・作業面・詳細。全機能のコンテナを可変幅にしPWAの縦向き固定を解除。
- 現行テーブル・目標・ToDoを削除しない。Freeプラン維持。新テーブルは家族メンバー限定のRLSと最小権限を設定。
