# 備蓄・在庫管理

更新: 2026-09-20

既存の家の在庫を、食品・調味料・日用品・掃除用品・防災品をまとめて管理できる備蓄機能へ拡張する。

- 現在数と最低在庫数を登録し、現在数が最低数を下回ると自動で「補充が必要」にする。
- 数量を管理しない品物は、従来どおり「十分／残りわずか／なし」を手動で選べる。
- 品名・メモの検索、カテゴリ絞り込み、補充が必要な品物だけの表示に対応する。
- 不足品は個別または一括で買い物リストへ追加する。既に未購入リストにある同名品は重複追加しない。
- 備蓄カテゴリは既存の買い物カテゴリへ変換する。食品・調味料は食材、日用品・掃除用品・防災品は日用品として追加する。
- 既存の「食材」在庫は「食品」に移行する。品名・数量・期限・履歴は保持する。
- 家族メンバーだけが閲覧・編集できる既存RLSを維持し、匿名・非メンバーには公開しない。

## 受け入れ確認

最低在庫数による不足判定、0個の在庫なし判定、数量の増減、検索、カテゴリ絞り込み、一括追加の重複回避、カテゴリ変換、期限表示、既存データ保持、家族外アクセス拒否を確認する。
