# 現行プロダクト仕様

更新: 2026-10-02。コードとマイグレーションを基準とする。このブランチには未マージの②③改善も含み、本番反映状況はPR/デプロイ記録で区別する。

## 利用者と画面

家族2人のメール/パスワード認証とapp_members許可リスト。一般登録画面はない。ホームは4機能選択、共通ナビは選ぶ/お金/暮らし/未来/ポイント。スマホ・iPad・PCで同じURLとDBを使う可変幅UI。実機の全操作は未検証。

## 現在の機能

- お金: 貸借、部分返済/取消、差引。月別支出、レシート画像、端末内OCR。日付・店名・金額は候補として入力し、人が修正/保存。銀行連携や送金はない。
- 買い物: 複数品名追加、食材/日用品/その他、購入済み、購入履歴から定番品追加。在庫・レシピと連携。
- 在庫: 食品/調味料/日用品/掃除用品/防災品/その他。現在数、最低数、単位、期限、メモ。数量管理なしなら十分/残りわずか/なし。検索と絞り込み。同名未購入品の重複はクライアントで回避するが別端末の完全同時追加を一意制約で保証しない。[詳細](stockpile-inventory.md)
- 家事: 期限超過/今日/今週など、履歴、検索・分類・有効状態。日週月年の間隔、曜日固定、毎月、毎年、単発。未完了は翌日も期限超過として残る。完了履歴/次回期限をRPCで一括更新し同日重複を防止。家電の不明型番/仮頻度を区別。[詳細](housework.md)
- レシピ: 材料・手順の一括保存/編集、検索、元リンク、在庫照合、不足品追加。対応WebのRecipe構造化データ、YouTubeタイトル・概要欄、Instagramリンク保存/手入力。動画理解・字幕・コメント・ログイン制限回避は未実装。
- 未来: Wishの本人/配偶者/ふたり、進捗、相談。人生ToDoの担当・優先度・状態。目標のルート/フェーズ/節目/共通ToDo、関連グラフ、ロードマップ、年月タイムライン。保存/達成/アーカイブを分離し復元可。[詳細](life-planning-workspace.md)
- ポイント: 手動Todo、公式キャンペーン候補、本人による採用・確認・実施、個人別完了/サービス設定。ポイント付与を保証せず自動応募・課金しない。
- 通知: 朝夕のまとめ設定。アプリ内で時刻と未完了件数を評価。OS通知は許可済みの場合のみ。閉じたアプリへのPush配送は未実装。

## オフライン・更新（Draft②③）

- オフラインは閲覧のみ。家計キャッシュv12はユーザーIDと保存日時を持ち、本人・24時間未満のみ復元。旧版/他人/破損/未来日時は破棄。暗号化保管を保証しない。
- ログアウトで家計/メンバーのキャッシュを消去し、古い通信結果の書戻しも防ぐ。
- 新版通知→保存確認→明示更新。保存中・オフラインは更新不可。別タブを勝手に再読込しない。[詳細](pwa-updates.md)
- OCR資産/言語モデル/レシート画像の完全オフライン利用は保証しない。

## 制約・未完了

- Freeで漏洩パスワード保護は未有効。両実アカウント、実Data API/Realtime、iPhone/Android/Surfaceは[チェックリスト](two-member-verification.md)で管理。
- 定例家族会議/変更履歴の専用機能は、過去案にあっても現行UI/専用テーブルを確認できず実装済みとはしない。
- バックグラウンドPushは[仕様案](background-push-proposal.md)を作成し承認待ち（未実装）。課金・外部画像送信、本番マージ/公開も別途承認を必要とする。
