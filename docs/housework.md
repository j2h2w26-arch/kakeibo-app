# 家事機能仕様（第1段階）

更新: 2026-09-19

## 目的

忘れやすい定期家事を「次にいつやるか」と「前回いつやったか」で管理する。完了履歴は消さず、不要な家事は削除ではなく無効化する。

## 画面

「暮らし」内に「買い物・在庫」と「家事」の切り替えを設ける。家事画面は次の3タブで構成する。

- やること: 期限超過、今日、7日以内、その後の順で表示し、ワンタップで完了できる。
- 履歴: 家事名、完了日、完了者を表示する。
- 管理: 追加、編集、無効化、再有効化を行う。家事名・家電名・型番の検索と、カテゴリー・有効状態の絞り込みができる。

## 周期

- 完了日から一定間隔（日・週・月・年）
- 曜日固定
- 毎月の日付固定
- 毎年の月日固定
- 単発

月末や閏年で存在しない日付はその月の最終日に丸める。同じ家事を1日に二重完了できない。完了履歴の追加と次回期限の更新は同一トランザクションで行う。

## 家電

家電台帳とお手入れ家事を分けて管理し、1台の家電に複数のお手入れ項目を紐づける。初期登録は次の6台。

| 家電 | 型番 | 状態 |
|---|---|---|
| Panasonic エアコン | CS-255DFL-W | 確認済み |
| Panasonic 食器洗い乾燥機 | NP-TSP1 | 確認済み |
| TOSHIBA ドラム式洗濯乾燥機 | TW-127XP3 | 確認済み |
| eufy ロボット掃除機 | Omni C28 / ステーション T291X | 確認済み、細かな頻度は仮設定 |
| Dyson コードレス掃除機 | 未確認 | 水洗い方法を確定しない |
| Dyson 空気清浄ファン | 未確認 | 洗浄・交換方法を確定しない |

PanasonicとTOSHIBAは公式サポートの目安を反映する。eufyは使用状況と公式説明書の確認後に頻度を調整する。Dysonは型番を推測せず、ラベル確認後に公式手順へ更新する。

## データと権限

- `household_appliances`: 家電名、メーカー、型番、公式サポートURL、有効状態
- `household_chores`: 家事定義、家電との紐づけ、周期、次回期限、有効状態
- `household_chore_completions`: 完了日、完了者、完了メモ

3テーブルすべてでRLSを有効化し、`app_members`に登録された認証済み家族だけが利用できる。`anon`にはテーブル権限を付与しない。家事と家電の物理削除はクライアントAPIに公開しない。
